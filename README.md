# SAU Complaint Box

A static student complaint portal for South Asian University, built with HTML, CSS, and JavaScript.

## Files

- `index.html` — page structure and complaint form
- `style.css` — layout and responsive styling
- `script.js` — complaint submission and tracking interactions

## Current behavior

Complaint data is stored in JavaScript memory in the open browser tab. It does not persist after refreshing or closing the page, and submissions are not sent to a university system. A backend and database would be needed for persistent, shared complaint tracking.

## Run locally

Open `index.html` in a web browser.
